The dependencies, the books and the nineteen weeks

Three things you cannot see in a text list: which way the dependencies may point, which book each module actually sends you to, and where the calendar ends.

Historical snapshot. Drawn on 8 Sep 2026 from the C version and the old twelve-module plan, so file names end in .h and the module numbers (M1–M12) are one higher than today's track numbers from M2 on (old M1, the gate, was removed on 13 Sep). The dependency rule in section 01 still holds.

01

The dependency direction

The rule is one line long and it is the only architecture rule the repo has: the arrows may only point downwards. ds/ may use mem/ and sync/; neither of them may ever mention ds/. The build fails a violation.
